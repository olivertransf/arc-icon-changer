# Bundled Arc icons (`.icns`)

Three variants from [macOS Icons](https://macosicons.com/) (Arc).

| File | Role |
|------|------|
| `arc-icon-variant-1.icns` | Variant 1 |
| `arc-icon-variant-2.icns` | **Default** — used when you run `./apply.sh` with no arguments |
| `arc-icon-variant-3.icns` | Variant 3 |

Refresh from your Downloads folder (original long filenames from the site):

```bash
./sync-icons-from-downloads.sh
```
